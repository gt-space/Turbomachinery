# Turbomachinery
Repo for all scripts related to Turbomachinery on YJSP

## EPump
The primary goal of the YJSP turbomachinery team is to create a flight ready Electric Pump. 

## Turbopump
As a backup option, preliminary work is being carried out to size a turbopump. It is not the primary path due to the potentially high test complexity and hardware risk. However, the trade is still being evaluated, as running turbine off of tank pressure significantly decreases risk and switching from epump would remove the necessary time to develop a battery, for which their is no existing test infrastructure.
